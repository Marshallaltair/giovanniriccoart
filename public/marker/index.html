Marker

Tag colorati per file e cartelle su Windows 11, come nel Finder del Mac. Tasto destro, scegli un colore, e ritrovi tutto quando ti serve.

01Installazione

Un solo file, Marker-Setup.exe. Non servono diritti di amministratore, tranne un'unica conferma per i pallini sulle icone.

  1. Sblocca il file. Tasto destro su Marker-Setup.exe → Proprietà, spunta Sblocca in basso e premi OK. Così Windows non mostra la schermata blu “PC protetto da Windows”.
  2. Avvia il setup con un doppio clic e premi Installa.
  3. Conferma il permesso che Windows chiede una volta sola: serve ad attivare i pallini colorati sulle icone.
  4. Premi “Riavvia Esplora file”. La barra delle applicazioni sparisce per un secondo e torna: da quel momento il menu Tag è attivo.
Se hai già scaricato il file e vedi la schermata blu, premi Ulteriori informazioni e poi Esegui comunque.

02Assegnare un colore

Funziona su qualsiasi file e cartella, anche su più elementi selezionati insieme, sul disco del PC o su un NAS.

  1. Seleziona uno o più file o cartelle in Esplora file.
  2. Tasto destro → Tag → scegli un colore.
  3. Per togliere un colore, cliccalo di nuovo: la spunta indica i colori che gli elementi hanno già.
Un file può avere più colori insieme, come sul Mac. Con una selezione multipla, il clic aggiunge il colore a tutti; se tutti lo hanno già, lo toglie a tutti.

03Cosa vedi in Esplora file

Le cartelle cambiano colore. I file mostrano un pallino colorato nell'angolo in basso a sinistra dell'icona, anche sulle anteprime delle foto.

Su ogni icona Windows mostra un solo pallino. Se un file ha più colori vedi l'ultimo assegnato; l'elenco completo è nell'app Marker. Lo stesso vale per il colore delle cartelle.

04Esempio: scegliere le foto da stampare

Tre colori bastano per decidere: verde si stampa, giallo forse, rosso no. Poi Esplora file raggruppa le foto per colore da solo.

  1. Scorri le foto e assegna verde, giallo o rosso con il tasto destro. Selezionandone più insieme vai più veloce.
  2. Passa alla visualizzazione Dettagli (menu Visualizza → Dettagli).
  3. Tasto destro nello spazio vuoto → Raggruppa per → Tag. Se “Tag” non compare, scegli Altro… e spuntalo.
  4. Seleziona il gruppo Verde cliccando sulla sua intestazione e manda in stampa.

In alternativa, con la ricerca

Nella casella di ricerca della cartella scrivi tag:verde: restano solo le foto verdi. Poi Ctrl+A e stampa.

Ordinare e raggruppare direttamente in Esplora file funziona con i formati che hanno il campo Tag di Windows: JPG, TIFF, HEIC, Word, Excel, PowerPoint e MP4. Per gli altri formati (PNG, PSD, PDF…) usa l'app Marker, che li gestisce tutti.

05L'app Marker

La trovi nel menu Start, oppure con tasto destro → Tag → Apri Marker. Mostra tutti i file taggati, ovunque si trovino, divisi per colore.

Cosa puoi fare

  • Filtrare per colore dalla barra a sinistra, o cercare per nome e cartella.
  • Ordinare per nome, tag, cartella, data, dimensione o tipo. I numeri nei nomi si ordinano bene: shot_010 viene prima di shot_100.
  • Raggruppare per tag con il pulsante in alto.
  • Trascinare i file dall'app verso Esplora file, Photoshop, Nuke o la stampante; oppure trascinarli sopra un colore a sinistra per taggarli.
  • Doppio clic per aprire un file; tasto destro → Mostra in Esplora file per andare alla sua cartella.

06Dare un nome ai colori

Puoi chiamare i colori come ti serve: “Stampa”, “Forse”, “No”, oppure “Approvato”, “Da rifare”. Il nuovo nome compare nel menu del tasto destro, nell'app e nel campo Tag di Windows.

  1. Apri l'app Marker e premi Impostazioni…
  2. Scrivi i nuovi nomi accanto ai colori e premi Salva.
  3. Con i nomi dell'esempio, la ricerca diventa tag:stampa.
Scegli i nomi prima di taggare molti file. Nel campo Tag di Windows i file già taggati mantengono il nome vecchio finché non riassegni il colore.

07Domande frequenti

Dove finiscono i tag, cosa succede ai file, cosa Marker non può fare.

Dove vengono salvati i tag?

Sul file stesso, non in un database. Sui dischi del PC e sulla maggior parte dei NAS restano nascosti dentro il file e lo seguono se lo sposti o lo rinomini. Sui dischi che non lo permettono (chiavette exFAT, alcuni NAS) Marker usa un piccolo file nascosto nella cartella. In entrambi i casi un altro PC con Marker installato vede gli stessi colori.

Marker modifica le mie foto?

L'immagine no. Sui formati che hanno il campo Tag di Windows (JPG, TIFF, HEIC, Office, MP4) Marker scrive il nome del colore nei metadati, così Esplora file può raggrupparli. La data di modifica del file non cambia. Se preferisci non toccare i metadati, togli la spunta in Impostazioni: i colori funzionano lo stesso.

Perché non vedo il colore sotto il nome del file, come sul Mac?

Esplora file non permette ai programmi di colorare il nome dei file. Marker usa le due cose che Windows consente: il pallino sull'icona e l'icona colorata delle cartelle.

Quando si perdono i tag?

Come sul Mac, quando un file passa da qualcosa che non conserva queste informazioni: archivi ZIP, invio via web o email, alcuni servizi cloud. Copiare tra dischi del PC e NAS non li perde.

Non vedo il menu Tag o i pallini.

Riavvia Esplora file: rilancia il setup e premi “Riavvia Esplora file”, oppure esci dall'account e rientra. Se la richiesta di permesso durante l'installazione è stata rifiutata, i pallini non sono attivi: rilancia il setup e conferma.

Come si disinstalla?

Impostazioni di Windows → App → App installate → Marker → Disinstalla. I tag restano sui file: reinstallando Marker li ritrovi tutti.
